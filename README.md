# Hi there, I'm Shern Wu 👋

我是具備紮實訓練的前端網站開發人員，近期完成香港僱員再培訓局 (ERB) 前端網站開發專業證書。我熱衷於使用AI工具開發各種網頁或應用的可能性，最近應用網頁PWA技術建置了好幾款可以在手機端流暢運作的小遊戲及應用，之後再把全端的練習都做過一遍我就有了可以做大型網站的基礎能力了。

### 🛠️ 核心技術棧

* **前端開發**: HTML5, CSS3, JavaScript (ES6+), React, Vite, Tailwind CSS
* **進階技術**: PWA (漸進式網頁應用), HTML5 Canvas 遊戲開發
* **設計與影音**: Adobe Photoshop, Illustrator, Premiere Pro, After Effects

#### 🚌 香港即時到站查詢系統 (HK Bus PWA)
